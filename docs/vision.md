# Бачення проєкту «Система управління студентами»

## Мета

Система замінює розрізнені таблиці з оцінками єдиним вебзастосунком, у якому
викладач веде облік студентів, академічних груп, дисциплін і оцінок, а студент
у будь-який момент бачить свої актуальні результати.

## Користувачі

| Роль | Потреби |
| --- | --- |
| Викладач | Додавати й видаляти студентів, виставляти та змінювати оцінки, бачити успішність групи, експортувати оцінки |
| Студент | Входити в систему і переглядати лише власні оцінки та середній бал |

## Основні функції

- Облік студентів і академічних груп: додавання, редагування, видалення.
- Виставлення та зміна оцінок за 100-бальною шкалою з переведенням у шкалу ECTS.
- Список студентів групи з середнім балом, рейтинг і пошук за прізвищем.
- Особистий кабінет студента з його оцінками.
- REST API для клієнтського застосунку.
- Експорт оцінок у CSV для деканату.

## Поза межами проєкту

- Розклад занять і бронювання аудиторій.
- Оплата навчання та фінансовий облік.
- Дистанційне навчання: матеріали курсів, тести, відеозаняття.
